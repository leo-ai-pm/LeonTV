## 独立 API 与浏览器验证

统筹使用空密钥配置、拦截后端外网的隔离应用，前后端均为真实本地服务，未重启用户共享服务或修改已有项目资料。

- **创建与查回：** 同键同参数返回同一个运行；变参返回 409，自报请求哈希等额外字段被拒绝。8 个并发 HTTP 创建只形成一个运行；另有多进程锁复验。
- **真实界面：** 从空白 Studio 项目创建运行，查看计划、来源摘要、依赖、质量、计数与事件；实际测试视频可播放，15 秒、9:16。运行历史标签随最新快照更新。
- **刷新和重启：** 最终冻结代码重启后，界面查回同一运行，revision、事件序号和供应商次数不变；在请求键持久化后立即刷新，也能查回原请求。检查点续跑复用 reference v1，最终仍为正常的 3 次测试供应商步骤。
- **未决操作：** 结果未知时阻断改版、续跑和接受。停止不会清除未决操作；对账复用原 operation。对账完成后的整条链路总提交 3 次、查询 1 次，没有重复提交原操作。
- **质量与额度：** unknown/rejected 阻断后代与终审；一次返工情境只修复受影响产物。零测试额度不发生供应商提交。这些判定只证明 fixture 门禁。
- **版本与终审：** 改版后旧决定无效，即使成片文件哈希相同也不能复用旧终审；未变的参考产物保持原版本。重复相同终审只记录一条决定，变更同键决定被拒绝；实际 UI 完成测试接受与测试退回。
- **私有边界：** 私有状态不在静态目录；路径穿越、符号链接、额外文件路径参数及原始正文/回执/反馈的暴露受到负向检查。合法受控媒体仍可读取。

审查发现并修复了未决结果经「改版→续跑」绕过门禁的问题，同时修正前端 scopes 数据形状、空项目来源 ID 和历史列表状态滞后。修复后重新执行相应用例。
