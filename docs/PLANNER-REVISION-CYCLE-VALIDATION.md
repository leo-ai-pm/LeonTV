# 有限改稿与独立复核验收 · D24

2026-10-24。本轮在原Planner任务内接通“规划v1 → 独立首审 → 有限改稿v2 → 独立复核”。一次显式启动后由同一worker自动交接，审阅反馈会实际改变已保存的测试计划。模型响应为合成实现，任务、工具接收、版本、差异、范围验证、持久记录、停止与恢复均使用实际产品代码。

这完成了产品内有界改稿机制；真实模型协作、实际作品质量及人工验收仍待接入。[接口合同](./PLANNER-REVISION-CYCLE-API.md)。

## 已交付行为

- 复用原API、创建／动作幂等键、私有journal、执行锁、pending operation与intent／receipt；不另建运行系统。旧D23首审、旧五场景和normal语义保持兼容。
- 首审accepted直接结束v1，不制造缺陷。首审缺证或无可改范围就停止，不补造来源事实。
- 只有有效拒绝报告及D18 `content_repair_ready`提案可以启动一次Repairer。回执严格回显任务、操作、来源、父版本、首审报告及完整提案绑定；仅允许字段发生实际变化的候选才能追加v2。
- 无变化、越权修改、错误binding或无效响应均保留v1并停止。依赖后继进入复核范围，不自动获得编辑权。
- Rechecker使用全新上下文与完整来源／v2／原五规则，绑定确切v1拒绝报告和提案，不继承Planner或Repairer聊天、推理及自评。
- 每个旧问题必须恰有一项解决状态，保留原来源段与镜头定位；未解决／缺证必须与同规则的新问题对应。完整五规则仍可发现新问题。v1结论不能给v2放行。
- 四角色共用最多6次调用意图；首审、内容改稿及复核各最多1次，付费调用上限0。常规完整路径为5次。复核再拒绝、缺证或非法就停止，不自动创建v3。
- 确认回执恢复只处理原结果，无确认回执不重发。暂停阻止后续委派并保存迟到回执，显式续行不重置次数或版本。

仅新场景追加`revision_cycle`。列表只含元数据，详情才返回父计划、首审报告、提案及复核报告；不返回原始响应或上下文。前端重新计算允许范围、真实字段差异和摘要，沿用A「放映室」展示v1、v2、旧问题及五项复核。实际`quality_status`始终`not_reviewed`，normal与production仍关闭。

| 合成场景 | 当前计划 | 结果 |
| --- | --- | --- |
| `revision_accepted` | v2 | 合成复核接受；真实质量未审核 |
| `revision_rejected` | v2 | 再次拒绝，停止，不创建v3 |
| `revision_needs_input` | v1 | 缺证停止，未委派改稿 |
| `revision_invalid` | v1 | 无效候选被阻断，未保存v2 |
| `revision_response_unknown` | v1 | 保留Repairer原意图，不重调 |
| `recheck_unknown` | v2 | 有效复核缺证，停止 |
| `recheck_response_unknown` | v2 | 保留Rechecker原意图，不重调 |
| `recheck_invalid` | v2 | 无有效复核报告，停止 |

## 校验与性能

独立审查确认并修复两处边界：新复核纯合同曾允许任意parent+1，现明确只允许v1→v2；Repairer层级过深的JSON曾留下反复恢复的received状态，现归`REPAIR_INVALID`并完成原回执处理，不保存v2或启动复核。两处都有先复现后修复的负例。

八任务联调进一步暴露重复校验成本。现在只缓存来源无关的公共system／schema模板，每次仍重建当前输入并完整核对来源、计划、报告及规则；返回对象按值隔离，不缓存私有任务或已验结果。事务入口仍检查全部历史，未改变的读取省去出口重复校验，任何净修改仍全量再验后写入。

状态变化比较使用严格JSON类型树、稳定编码与SHA256，不用Python容器相等，也不让JSON序列化把tuple／整数键静默修成合法值；检测bool／int／float类型变化，拒绝不符合原schema的替换，并拒绝非有限数、非JSON值、循环和非法UTF8。此检查不改变原frame／source摘要算法。

同一份未修改的8个合成任务、130帧历史，在本机无profiler测量：

| 操作 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 只读事务 | 0.567秒 | 0.279秒 |
| 任务详情get | 1.759秒 | 0.824秒 |
| 列表8条 | 5.852秒 | 2.755秒 |

这是小型合成数据的局部测量，不代表真实长剧本或生产负载SLA。原130帧上下文／hash完整重放，state文件字节不变；公共模板的跨来源、并发、调用方突变与每次输入校验均有独立检查。
