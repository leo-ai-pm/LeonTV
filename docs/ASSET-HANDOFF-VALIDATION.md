## 实测发现与处理

- 旧图片路径缺少稳定意图与回执。已新增显式 `save_path`、提交前记录、排他锁及原任务恢复；无 ID 的未知提交和失败终态禁止重发。旧随机目录调用仍需调用者改用稳定路径才能防重。
- 原请求／查询客户端在本次查询中发生 TLS 连接异常。已按相同已受理任务 ID，用 HTTPx 的 GET 获取真实结果并补交付，没有重复生成。该恢复接线属于受控试制，尚未作为新的产品运行 API 提供。
- 请求固定 `gpt-image-2-all / 1k / medium / 9:16`；文档写 864×1536，实际三张均为 **1440×2560 WEBP**。单独冻结交付兼容条件，保留原始字节并转存 PNG；解码 RGB 像素摘要一致，未缩放、未裁切。账单仍逐笔核对，未把文档像素值当作真实结果。
- 核费索引曾遇到历史非字典元数据。保留原冻结程序，以单独兼容版本修复索引；费用未确认时子任务被拦住，未新增生成。原调用、来源和限额没有重置。
