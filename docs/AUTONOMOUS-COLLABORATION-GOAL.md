# LeonTV自主协作产品目标

2026-10-22｜目标v1冻结。**用户已确认将自主协作纳入产品目标；整体尚未实现、未验收。** 本文件定义目标与验收，不是已交付能力或新的执行授权。

用户明确短片Brief、来源、质量要求与授权范围后，总控Agent自行规划、委派制作角色并推进交付；独立Reviewer依据实际产物提出可定位的问题，总控在限额内组织局部返工，最终由用户验证当前版本并接受或退回。正常路径不要求人工逐阶段点击推进，异常仍允许暂停、求助或接管。

允许固定角色、预设任务图及受限交接；动态自由聊天不是Multi-Agent的必要条件，也不作为本目标验收要求。角色名称或流程图本身不能证明本产品自主协作闭环成立。标准A2A、跨服务身份与长期Personal Agent另行设计，不作为首个协作闭环的前提。

## 分阶段目标与验收

以下均为待实现目标；每阶段保留真实模型／工具轨迹及对应负例，合成检查与真实行为分别记证。

| 阶段 | 目标 | 可核验的完成条件 |
| --- | --- | --- |
| 1 总控规划与委派 | 从冻结Brief生成有依赖的任务，按能力交给制作角色。 | 每项有目标、负责人、输入引用、依赖、交付物、完成依据及工具／权限范围；至少一条真实委派→角色执行→交接轨迹。来源、制作要求、产物版本和上下文引用可追踪；旧稿／错版本不能覆盖新版本。 |
| 2 制作与独立审阅 | 编剧／分镜导演、素材、音视频与后期等角色按任务制作；Reviewer独立检查。 | 角色按实际需要启用并交付可读取产物；Reviewer使用独立判断上下文，读取实际版本、来源与规则，给出accepted／rejected／unknown及证据定位。生成者自报成功不能代替审阅；同底层模型的独立调用也不自动证明审阅可靠。 |
| 3 局部返工闭环 | 总控根据审阅问题调整受影响任务，再交独立核验。 | 至少一条真实“问题证据→改变任务／工具／参数或产物→新版本→复核”轨迹及无需返工的正例。无关合格产物保留；受影响后继及旧审阅失效，新版本重新核验。必需质量unknown／rejected不能自动跨关。 |
| 4 授权内运行与恢复 | 委派继承预算／权限，停止与重启不丢版本、账目或未决调用。 | 子任务只能缩小授权，全部角色／审阅／失败／重试和未决预占累计受总限额约束；并发、换角色／任务、停启不重置。停止阻止后续新委派与提交；在途未知保留原身份／费用暴露，不伪取消或盲重发。恢复复用已确认结果；显式新意图另记并继续承担旧未知，不冒称原操作已恢复。 |
| 5 当前版本人工终验 | 交付可播放短片、版本清单、审阅证据和费用摘要，由用户作最终决定。 | 最终决定绑定当前产物hash、来源／依赖及有效审阅；旧版本／缺证不得正常放行。记录中途人工推进、异常接管和最终决定，正常路径中途逐阶段推进为0次，最终有明确接受或退回；不能将接管隐藏成自主完成，或由模型代签用户接受。 |

## 整体验收与当前边界

首次整体验收以一份范围明确的真实短片任务为单位，覆盖正常交付、问题返工、版本失配、越权／额度耗尽及未知停止恢复；逐项保留原始证据的私有引用。所有角色共享同一任务来源与授权边界，产物／审阅／返工／费用／人工决定能按版本关联；硬门禁失败不能用平均分抵消。具体模型、工具、限额与评测样本在对应迭代冻结，本目标不承诺成功率、上线日期或多Agent更省钱。

执行完成、Reviewer质量结论和用户接受分别报告；用户退回保留原因并按权限返工或停止，不能把“已作最终决定”计为质量通过或用户接受。

已有受控运行、Brief／规划持久化及协议／费用门禁基础，验证范围见[D08](./BRIEF-PLANNER-VALIDATION.md)、[D09](./PLANNER-EXECUTION-VALIDATION.md)、[D10](./PLANNER-RESPONSES-VALIDATION.md)。截至本目标记录时，首个真实分镜pilot仍有无HTTP回执的未决调用，尚无已验收分镜；真实制作、独立内容Reviewer、自动局部返工与完整自主协作未由此获得证明，生产runtime仍关闭。目标确认不扩大现有调用／媒体／预算权限。

目标文档就绪后保持冻结；后续实现与真实结果分别留验收记录。取得实际分镜的私有引用后再做独立语义评阅，不复抄私有剧本、不预评分，也不因单次输出修改目标或放宽门槛。
