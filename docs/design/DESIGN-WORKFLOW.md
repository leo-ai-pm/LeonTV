## 设计顺序

1. 明确创作者主流程：给剧本、制作要求和预算，Agent自主规划与制作，用户查看进度并在必要异常和最终看片时介入。
2. 梳理任务创建、生产进度、异常处理、最终验收的关键状态。画布与六阶段仍是高级入口。
3. 通过UI UX Pro Max进行设计系统和目标UX查询，验证推荐的产品类别与本项目任务型工作台相符。视频编辑器素材可提供视觉参考，其时间线交互不自动成为产品主流程。搜索无命中或不匹配时明确降级依据。
4. 交付同一核心流程的三个静态视觉方向，记录主参考、内容层级、字体/色彩/间距角色和取舍，供产品负责人选择。
5. 对必要变化应用Emil原则：先判断频次和目的，优先CSS，动作可中断，保留焦点与最终语义状态；支持减少动态效果、触屏及键盘操作。
6. 以真实浏览器检查桌面和窄屏、焦点、快速切换、减少动态效果、可见错误与恢复状态。源代码中的性能表述不能替代实测。
