# LeonTV 路线图

目标是从可控的视频创作工作台，逐步演进为 Agent Harness，再探索更长期的 Personal Agent。每一阶段以可复核的真实行为验收，不以演示文案或目录名称判断完成。

## 当前基础

- 本地 Web、项目工作台、自由画布与单次生成工具。
- A「放映室」创作简报入口，支持剧本、要求及预算草稿的真实私有保存、版本历史、冲突处理与刷新恢复；保存不授权或执行制作。
- 已保存简报版本冻结与持久规划任务，受限工具/反馈/结构校验循环；正常任务待授权，离线合成响应与真实执行清楚区分。
- 六阶段创作状态机与中间产物，部分阶段的评估与有限修正。
- 多服务商适配与 FFmpeg 媒体处理。
- 独立的确定性 Harness PoC，以及真实图像/视频 API 试制。
- 已接入 Studio、正式 API 和私有持久存储的 Harness 测试运行基础。

## 第一阶段：产品内可恢复运行

**状态：首个测试模式产品切片已接入；真实生产运行尚未验收。**

正式 FastAPI、持久存储与 Studio 面板已连接。可创建和按键查回运行，检查事件、测试额度、版本依赖和质量状态，执行停止、恢复、原操作对账、局部改版和测试终审。刷新与后端重启恢复已在隔离真实应用中验证。[验证范围](./HARNESS-RUNTIME-VALIDATION.md)。

此切片只用确定性 Planner/Reviewer/供应商与 TEST 素材，付费限额为零。来源只绑定摘要，不解析真实剧本；质量和终审是测试判断，生产费用保护尚未由此获得验证。它交付运行机制，完整自主创作仍需第二阶段。

## 第二阶段：真实创作与质量闭环

**状态：Brief→规划任务及离线工具反馈闭环已接入；真实模型与制作质量闭环待实现。**

制作输入的私有持久化已接入正式前端与 [D07 简报接口](./CREATOR-BRIEF-API.md)，预算仍为未授权草稿。[D08规划任务](./BRIEF-PLANNER-API.md)已冻结选定版本并接入受限工具反馈循环，使用合成模型响应验收恢复与有限修正。[D09执行控制](./PLANNER-EXECUTION-API.md)已加入持久授权、原子预占/调用许可与保守回执处理，使用合成传输验收。下一步核实供应商文本端点、账户费率、回执协议和输入计费上界，再以明确的小额方案接入模型并验收实际规划；随后接入独立 Reviewer、图像、视频、音频与后期工具。运行必须绑定来源、制作要求、版本和有效授权，核验失败只重做受影响产物，并限制总次数与费用。

[D10 Responses适配](./PLANNER-RESPONSES-API.md)将文本协议选择、无状态请求及缓存/推理用量处理纳入同一执行门禁，保留历史Chat记录。此步交付代码兼容，不代表土豆候选模型、账户费率或真实文本质量已验证；下一项实际试跑仍需精确供应商协议、计费依据和绑定输入的小额方案。

2026-10-22已按用户指定的gemini-3.8-flash及原100元授权开展真实核费。[D11参数与试跑记录](./PLANNER-CHAT-OUTPUT-VALIDATION.md)确认两种Chat输出参数均未建立可靠计费硬界；M01完成读取来源动作，第二次调用无HTTP回执且保留未决预留，尚无分镜计划。当前先处理原未决操作及回执可观察性，再完成真实分镜、独立内容审阅与有界修正。正式生产费用保护和完整Harness产品仍待验收。

后续[D12与有限续试](./PLANNER-RECOVERY-VALIDATION.md)已补私有传输分类，并从真实拒绝结果定位、修正了新任务提示中缺少工具参数结构的问题。两次续试已核费但未通过实际提交工具；旧未知继续保留。下一项用完整参数合同的新任务取得真实结构合格分镜，再接独立内容Reviewer与受限返工；修改后的提示和完整协作均尚待真实验收。

[D13工具合同与安全反馈验证](./PLANNER-CONTRACT-VALIDATION.md)已增加显式开启的字段级错误反馈，默认判据和正式调用保持兼容。新任务实际读取来源成功，但提交时120秒无回执，已因新的unknown停止，尚无可审阅分镜。[D14回执采集与只读检查](./PLANNER-RECEIPT-RECOVERY-VALIDATION.md)已通过合成故障验收：独立采集进程先落盘再通知，观察者退出后仍可采证，迟到证据保持隔离，旧未决不清账、不盲重发。下一项用明确的新意图、有效权限与累计预算验证真实分镜提交，再接独立内容审阅和有限修正；本轮没有新增真实模型调用，正式生产继续禁用。

[D15经验风险接入](./PLANNER-LIVE-VALIDATION.md)已完成代码与合成验收：独立实验授权视图复用可靠回执采集，保留正式费用门禁；838项后端全量检查及统筹独立复跑通过。恢复登录后的首次调用保存完整HTTP200，但缺HTTP ID和新增reasoning usage形状不兼容，工具执行前停止；平台唯一费用观察¥0.001334，风险保留，无D02。先修正实验兼容，再用独立新意图取得实际工具接收分镜并逐笔核费；已用1次计入原4次上限，后续接独立Reviewer和按版本局部返工。开发窗口复核不能当产品审阅。

[D18独立Reviewer实测](./PLANNER-REVIEW-VALIDATION.md)已完成：1060项全量检查通过；R01对实际F01 v1给出五项 accepted，平台核费¥0.014428后为 `review_completed`。本段累计5次＝4 Planner＋1 Reviewer，旧4条unknown不变；风险41.12元不是消费。返工任务／范围约束已有合成覆盖，本次无需返工，真实负向返工与复核闭环仍待验收。下一项接素材角色、角色／场景定型与逐镜文生图，再衔接图生视频、后期和人工终验；沿用原总预算与版本引用，新的角色子范围单独冻结，不重置历史记录。

[D19素材角色实测](./ASSET-HANDOFF-VALIDATION.md)已交付三张真实9:16首帧，1次素材文本＋4次图片提交（含1次明确失败后的独立重试）。净费用观察¥0.130818，风险占用46.12元不是消费，旧4条unknown不变。下一优先项是独立视觉Reviewer与局部返工，处理协议道具连续性及人物区分度，再用合格素材衔接双模型15秒视频；本轮没有视频／音频生成或正式运行开放。

[D20视觉审阅与局部返工](./ASSET-VISUAL-REVIEW-VALIDATION.md)已实际完成：最终图片组合为v1/v3/v2，独立复核accepted；三次新图片提交平台费用¥0.12，累计风险49.12元不是消费。1174项测试与5子测试通过。该结果成为后续双模型15秒视频试制的输入，产品内视觉模型、自主调度与核费仍待正式集成，用户终验待进行。

[D21视频实测](./VIDEO-GENERATION-VALIDATION.md)当前被供应商通道故障阻断。2026-10-24经批准重建浏览器并核对登录、价格和参考图后，按同一简报及图片版本1/3/2向MiniMax H3、Seedance 2.5各提交1次15秒请求。两次均返回HTTP502，含上游HTTP503 `model_not_found / No available channel`，没有新视频或音频，视频质量与人工验收未进行。对应错误记录费用观察为¥0；累计风险¥69.37继续保留，原¥100授权、旧操作和历史未知不变。本轮两次额度已用完，H3亦已达历史累计上限，不自动重试或切模型。纯视频简报合同已实现，正式视频/VLM/核费调度仍待集成，生产及默认回执采集继续关闭。

视频试制分支仍等待原通道恢复，或用户选定可用替代渠道/模型，再冻结继承预算、累计次数与版本的新意图；不重复要求已有密钥、素材或客服回复。新意图必须复核参考图URL有效期，保留已接受图片、旧回执与累计计数。通道恢复后继续视频试制、独立质量核验与版本绑定的人工终验。

产品开发可并行推进。[D23规划到独立审阅交接](./PLANNER-COLLABORATION-API.md)把已有首审合同接入 `/creator`、原Planner API、持久任务和工作线程。显式合成场景一次续行后自动完成 Planner→Reviewer，保存五项标准、定位问题和有限返工提案；全部角色累计最多6次、Reviewer最多1次、付费调用上限0。已有回执恢复复用，无确认回执不重调，旧任务无需迁移。实际质量仍未审核；真实模型执行、按提案生成新版本与独立复核尚未接通。[验收范围](./PLANNER-COLLABORATION-VALIDATION.md)。

验收重点：模型真的调用工具并处理回执；检查不合格结果后，反馈能够触发对应局部修正；未知、超时和超预算不继续盲目提交；最终文件满足时长、画幅、角色连续性、对白、动作与音画要求。

## 第三阶段：Agent 协作

**状态：首个 Planner→Reviewer 自动交接已接入产品任务的合成执行路径；完整自主协作尚未验收。**

接下来的开发顺序：先实现拒绝／缺证后的版本化处理与独立复核，让反馈实际改变后续行动；再把真实角色执行接入统一授权、累计额度与回执恢复，随后接入素材／视觉审阅／视频工具和最终人工验收。D23没有另建运行系统，也没有把历史实验结果导入为正式生产授权。视频供应商故障不阻断前面的协作开发。

按[自主协作目标v1](./AUTONOMOUS-COLLABORATION-GOAL.md)分阶段推进：总控规划／任务委派与版本上下文→制作角色及独立Reviewer→证据驱动局部返工→预算权限继承、未知停止与恢复→当前版本人工终验。允许固定角色和预设任务图，动态自由聊天不是Multi-Agent的必要条件；标准A2A与跨服务身份另行设计。

验收重点：真实任务／工具／交接可追踪，独立审阅反馈实际改变后续行动；改版使受影响审阅失效并重新核验，无关合格产物保留。所有角色及未决费用累计受同一授权限制，停止／恢复不清账或盲重发；正常路径无需逐阶段人工推进，最终接受／退回绑定当前版本。首个真实分镜pilot未决不记成功，目标确认不等于生产已启用或完整Harness已验收。

## 第四阶段：Personal Agent

**状态：长期探索。**

在稳定创作闭环之上增加持久偏好、跨任务记忆、长期目标和授权范围内的主动工作。不能仅把多 Agent 调度称为 Personal Agent。

验收重点：记忆来源和修改可解释，个人数据可控制，权限与长期任务可撤回；能跨任务持续完成目标并在需要时向人求助。

本路线图不承诺尚未验证的模型成功率或上线日期。当前从第一阶段的测试运行基础继续推进第二阶段，以真实创作任务验证完整 Harness 产品能力。
