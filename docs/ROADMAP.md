# LeonTV 路线图

目标是从可控的视频创作工作台，逐步演进为 Agent Harness，再探索更长期的 Personal Agent。每一阶段以可复核的真实行为验收，不以演示文案或目录名称判断完成。

## 当前基础

- 本地 Web、项目工作台、自由画布与单次生成工具。
- 六阶段创作状态机与中间产物，部分阶段的评估与有限修正。
- 多服务商适配与 FFmpeg 媒体处理。
- 独立的确定性 Harness PoC，以及真实图像/视频 API 试制。
- 已接入 Studio、正式 API 和私有持久存储的 Harness 测试运行基础。

[当前架构与实验边界](./ARCHITECTURE.md) · [真实结果演示](./DEMO.md)

## 第一阶段：产品内可恢复运行

**状态：首个测试模式产品切片已接入；真实生产运行尚未验收。**

正式 FastAPI、持久存储与 Studio 面板已连接。可创建和按键查回运行，检查事件、测试额度、版本依赖和质量状态，执行停止、恢复、原操作对账、局部改版和测试终审。刷新与后端重启恢复已在隔离真实应用中验证。[验证范围](./HARNESS-RUNTIME-VALIDATION.md)。

此切片只用确定性 Planner/Reviewer/供应商与 TEST 素材，付费限额为零。来源只绑定摘要，不解析真实剧本；质量和终审是测试判断，生产费用保护尚未由此获得验证。它交付运行机制，完整自主创作仍需第二阶段。

## 第二阶段：真实创作与质量闭环

**状态：下一实施重点；部分生成基础已存在，完整闭环待实现。**

先把真实模型规划、受限工具反馈和独立 Reviewer 接入同一个持久 run，再连接图像、视频、音频与后期工具。保留同一来源、制作要求、版本和预算，核验失败只重做受影响产物，并限制总次数与费用。

产品负责人下一次需要确认的是一份具体试制方案：真实模型/接口能力、核实后的费用与单次/总额度、质量验收项和可接受的人工介入点。确认前可以继续零付费开发与离线验收，无须重新提交完整剧本或密钥。真实试制完成后，再由负责人看片并记录接受或退回。

验收重点：模型真的调用工具并处理回执；检查不合格结果后，反馈能够触发对应局部修正；未知、超时和超预算不继续盲目提交；最终文件满足时长、画幅、角色连续性、对白、动作与音画要求。

## 第三阶段：Agent 协作

**状态：规划方向。**

明确编剧、导演、素材与审查角色的任务合同、上下文与交接方式，在任务边界内协作。标准 A2A 协议、跨服务身份与权限还需具体设计和独立验证。

验收重点：跨角色依赖可追踪，错误能定位，预算和权限不因转交失效；降低人工中间操作的同时保留可干预与恢复能力。

## 第四阶段：Personal Agent

**状态：长期探索。**

在稳定创作闭环之上增加持久偏好、跨任务记忆、长期目标和授权范围内的主动工作。不能仅把多 Agent 调度称为 Personal Agent。

验收重点：记忆来源和修改可解释，个人数据可控制，权限与长期任务可撤回；能跨任务持续完成目标并在需要时向人求助。

本路线图不承诺尚未验证的模型成功率或上线日期。当前从第一阶段的测试运行基础继续推进第二阶段，以真实创作任务验证完整 Harness 产品能力。
