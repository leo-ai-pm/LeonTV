## 本轮发现并修复

- 同账户任一操作超风险后冻结全部后继任务，先保存超额事实，避免新任务绕行。
- 旧授权撤销后换发授权不因迟到费证自启动；明确续行复用原回执。`received` 始终要求原始回执存在。
- 前端允许“仅本地估价超额、平台费用未知／更低”的真实状态，未知不显示为零，不将估价写成平台扣费。
- 新 normal 任务首次报价前尚未冻结 kind／角色；前端仅对严格的空白 revision0 状态适配当前策略，已有历史不能升级，原待确认 scope／键保持。

实测另外发现土豆 `/api/log/self` 的 `id` 是筛选结果序号，两次独立导出均为 1。第二笔核费被原生唯一性检查阻断，没有继续生成。私有观察桥改用实际 `request_id` 摘要识别平台请求；已接受的第一条证据保留原样，只为完全相同的历史证据保存精确别名，并额外检查同一平台 request 不能通过新别名分配给其他操作。修正前脚本、被拒证据、原始导出与失败记录全部保留。

修正后离线验证原证据精确重放、第二笔不同请求、11 类错误证据和跨别名复用；原生 journal 字节不变。随后仅重启隔离观察服务，核对第二份原回执，再按原授权自动继续；没有重发这次模型请求、提高额度或重置次数。该问题属于私有平台观察适配，公开执行代码和冻结 manifest 没有改变。
