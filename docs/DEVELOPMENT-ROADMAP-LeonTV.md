# LeonTV 分阶段开发路线图

更新：2026-10-08。需求基线为 [桌面创作平台 PRD v0.1](./PRD-LibTV-桌面创作平台-v0.1.md)。范围仅桌面 Web。

## 阶段 1：品牌与画布基础版（当前交付）

- **已完成**：LeonTV 界面品牌与图标；项目列表、搜索、新建、复制、回收站及恢复；无模型密钥的演示项目。
- **已完成**：可平移、缩放、拖动、框选、连线的桌面画布；文本、分镜、图片、视频节点；节点属性、生成状态与版本切换；自动保存与冲突检查；最近 20 次画布结构操作的撤销/重做。
- **已完成**：旧六阶段会话可映射为画布，保留原会话数据及素材版本；原阶段视图继续使用。画布上的旧产物内容暂时只读，移动与连线可以保存。
- **已完成**：图片/视频节点调用现有临时工作台 API；运行前检查对应服务商密钥，失败展示配置入口；上游修改标记下游待更新。
- **验收证据**：前端生产构建通过；持久化单元测试通过；在桌面浏览器完成创建项目、编辑文本、添加图片节点、连线、自动保存和刷新恢复。
- **尚未完成**：多节点批量操作、节点删除引用提示、可靠的跨视图双向同步。故本阶段属于可体验基础版，尚未达到 PRD 的完整 V1 验收。

## 阶段 2：资产与分镜编辑（下一阶段）

覆盖 M02/M03/M05/M06/M07/M09。建立项目级资产索引和持久化上传；支持图片、视频检索、引用与删除保护。将旧项目的 `segment_id` 作为稳定关联键，让分镜节点编辑回写原会话并标记后续产物过期。补齐节点比例、时长、输入快照和运行时间。验收：资产可跨节点复用，重启后引用有效；抽取不同阶段的旧会话核对分镜、图片和版本一致。

## 阶段 3：片段预览与成片闭环

覆盖 M04/M08。按片段顺序预览，选择版本并调用现有拼接/导出能力；缺失或待更新素材在导出前提示。验收：在配置可用模型密钥的环境中，从分镜生成参考图和视频，局部重做后导出可播放文件，并能在项目里再次找到。

## 阶段 4：增强能力

按 PRD 的 P1 优先级推进剧本局部改写、角色与场景档案、时间线、模板和画布 Agent。P2 社区、3D、插件、团队与计费另行定义，不纳入桌面 V1。

## 当前运行限制

公开仓库仅提供无密钥的 `backend/config.yaml.example`；本地 `config.yaml`、会话、项目与生成产物不提交。真实图片和视频生成需要在设置中填写所选模型服务商的密钥。代码从压缩包解压目录初始化，未包含上游 Git 提交历史；代码来源与版权声明保留。

品牌对外发布前应完成商标与域名核查。LeonTV 是产品展示名称，代码来源和 MIT 许可证中的原作者署名继续保留。
