## 代码边界

`verified_current`从原控制和实际store重新获得一份完整验证过的snapshot，在这次判断内核验当前来源、grant、代码、lease、原unknown与固定父资金，再返回snapshot和authority。原`verify_current`入口仍自行读取真实状态，并对比调用者传入的payload；传入一份已签名或已重算hash的字典不能替代当前权限。

显式`RuntimeContinuedImageControl`与原`MediaExecution`绑定。同一次捕获判断中的原生候选、scope／grant、描述符、累计次数、费用及unknown门禁使用该次刚验证的实际snapshot。三个独立边界分别重新检查，不在控制对象、请求之间或取Key前后保存权限结论。事务内的既有payload仍须与新鲜真实payload完全匹配。

实现复用原媒体执行器、原collector、帧链和预算记录。旧v1路径与D40仅GET观察路径继续保留各自合同；没有延长原120秒permit、刷新旧nonce／日期、绕过原unknown、修改模型／分组或追加预算。
