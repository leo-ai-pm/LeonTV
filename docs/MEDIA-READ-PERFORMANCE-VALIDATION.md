## 改动与完整校验

- `store.inspection_snapshot` 在同步媒体GET内保留一次完整验证的已提交输入；每次嵌套读取仍重新打开文件、检查原字节及inode，并返回独立副本。正常／异常退出即清除，不跨请求复用账本。
- 单次原生重建内，完整类型化输入或完整不可变描述符绑定成功的纯值证明；减少描述符重复解析、已接受历史CORE上下文重建、manifest结构检查。计算消费构造键时冻结的同一份输入，避免调用方中途修改造成错误绑定。
- bool／int／float及负零保持区分；非JSON／过深／超节点输入回退原计算，失败不缓存。证明有条数、字节及节点上限，结束／异常／嵌套／线程／复制上下文边界均验证。
- **不缓存当前权限、时间、源码文件比对、资金门禁或私有文件可用性**。实际control／source／lease／fee／unknown门禁与文件完整解码、SHA／proof检查保留；路由、DTO、错误码和前端合同未改。
