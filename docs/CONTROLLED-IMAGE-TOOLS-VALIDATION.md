## 独立检查发现与修复

独立权限测试发现：verifier把JSON列表换成tuple后，普通JSON摘要仍可能相同，原实现会继续建立claim。现先严格验证JSON类型树再比较摘要；该反例通过，拒绝发生在派发前。
