显式GET只查询真实accepted task，在当前匹配的revision、lease、grant、代码与父证明下有界观察，不自动轮询或重试；POST暂停与GET观察分别判断。换revision后不能把旧POST移植到新authority来续GET。只读回执恢复及精确核费／交付导入继续按既有事实合同处理。

引用绑定确切的source operation、query、delivery ID、delivery hash及文件SHA，不按镜头名选择第一个旧操作。第二镜替代图片交付后，第三镜引用该新交付；即使图片内容相同，也不能替换来源ID。
